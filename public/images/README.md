# Pasta de imagens

Coloque os arquivos aqui **exatamente com estes nomes**. O app já está
configurado para usá-los automaticamente — se um arquivo não existir, a tela
continua funcionando com o visual atual (ilustração/gradiente) no lugar dele.

| Arquivo                 | Onde aparece                              | Tamanho recomendado          |
| ------------------------ | ------------------------------------------ | ----------------------------- |
| `especialista.jpg`       | Avatar da Dra. Anna Christina no chat      | quadrada, mín. 200×200px      |
| `produto-mockup.jpg`     | Card do produto STRIAÉ dentro do chat      | 4:3 ou 1:1, mín. 800×600px    |
| `hero.jpg`               | Fundo da tela inicial do funil (`/funil`)  | vertical/retrato, mín. 800×1200px |

Pode ser `.jpg`, `.jpeg`, `.png` ou `.webp` — só ajuste a extensão no nome
acima para bater com o arquivo que você adicionar (ex: `especialista.png`).
Se usar uma extensão diferente de `.jpg`, me avise para eu atualizar a
referência no código.

Depois de adicionar os arquivos, é só recarregar a página — não precisa
reiniciar o servidor.
